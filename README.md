PETIT GÉNIE — site GitHub Pages

Contenu :
- index.html : page d'accueil
- images/ : six images recadrées depuis la capture fournie

Pour publier sur GitHub :
1. Décompressez petit-genie-github.zip.
2. Ouvrez votre dépôt GitHub.
3. Cliquez sur Add file > Upload files.
4. Envoyez index.html ET le dossier images (avec les six images).
5. Cliquez sur Commit changes.
6. Dans Settings > Pages, choisissez Deploy from a branch, puis main et / (root), puis Save.

Important : gardez le dossier images à côté de index.html. Les boutons de catégories affichent pour le moment un message de démonstration ; les leçons peuvent être ajoutées ensuite.
